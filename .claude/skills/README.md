# Project skills

Text-only agent skills copied from https://github.com/gamedev-skills/awesome-gamedev-agent-skills (Apache-2.0, see
`LICENSE-awesome-gamedev-agent-skills`). Only the ones this project can use are kept, and they were checked for scripts, hooks and
network calls (there are none: they are markdown; the helper scripts of the upstream repo were removed):

- `godot-gdscript`, `godot-gdscript-headless-testing`: how to write GDScript 4.x and run tests with `godot --headless`.
- `game-ai`: state machines, steering and A* for units and enemies.
- `input-systems`: touch and mouse input, gestures.
- `performance-optimization`: frame budget for tablets.
- `godot-multiplayer`: for the last stage.
