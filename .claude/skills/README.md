# Project skills

Agent skills for this project, copied from https://github.com/gamedev-skills/awesome-gamedev-agent-skills (Apache-2.0, see
`LICENSE-awesome-gamedev-agent-skills`). Only the ones that apply to a Godot 3D voxel RTS are included; the rest of that
collection (other engines, 2D tilemaps, C#, genres we are not making) is left out. Update by copying from the upstream repo.

Godot: gdscript, 3d-essentials, nodes-scenes, signals-groups, physics, ui-control, shaders, resources, gdscript-headless-testing, multiplayer (for the last stage).
Disciplines: game-ai (FSM, A*, steering for units), ai-behavior-trees-utility-ai (unit task AI), camera-systems, input-systems (touch),
game-ui-ux, performance-optimization (tablet budget), procedural-gen, create-game-assets (placeholder -> real art), game-feel, level-design.
Workflow: prototype-fast.
